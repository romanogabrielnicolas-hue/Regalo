# Para Juli ❤️ — React + Vite

Página romántica hecha con React, CSS animado y Lucide React. Las microinteracciones están inspiradas en el estilo de Uiverse y son CSS originales.

## Cómo ejecutarla
1. Extraé el ZIP y abrí la carpeta `juli_react_uiverse` en Visual Studio Code.
2. Abrí una terminal en esa carpeta.
3. Ejecutá `npm install`.
4. Ejecutá `npm run dev`.
5. Abrí la dirección local que muestre Vite (normalmente `http://localhost:5173`).

## Archivos principales
- `src/main.jsx`: componente React y botón sorpresa.
- `src/style.css`: diseño adaptable y animaciones.
- `index.html`: documento HTML base.
- `package.json`: dependencias y comandos.

Las fuentes de Google Fonts requieren conexión; hay fuentes alternativas si no cargan.
